You are working on a new Python project called RAFIQ.

Your task is to implement PHASE 01 — PROJECT FOUNDATION ONLY.

RAFIQ is intended to become a completely offline AI system built from scratch. The long-term goal is to create a lightweight intelligent assistant specialized in Python that can eventually understand Arabic, English, Egyptian Arabic, basic Franco-Arabic, natural-language instructions, code, stories, context, memory, reasoning, code generation, and code debugging.

IMPORTANT PROJECT RULES:

Python only.
No Internet access.
No external APIs.
No cloud services.
Do not use OpenAI, ChatGPT, Claude, Gemini, Qwen, Llama, Mistral, Ollama, or any other pretrained AI/LLM.
Do not download or import a pretrained model.
Everything related to the intelligence system must eventually be implemented from scratch.
Use lightweight standard Python libraries whenever possible.
Keep the architecture modular and suitable for low-RAM computers.
Do not implement future phases yet.
Do not create fake AI behavior using hundreds of hardcoded responses.
Do not delete existing useful project files without inspecting them first.

For this phase, create a clean and scalable project architecture.

Create an appropriate structure similar to:

    __init__.py

    __init__.py

Implement only the foundation:

clean startup/shutdown

The program must start successfully from main.py.

The initial output should clearly indicate that RAFIQ has started, but DO NOT pretend that the AI is already intelligent.

Add a small diagnostic system so the project can report:
